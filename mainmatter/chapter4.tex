Together with the fundamental numerical method schemes described to be able to solve Maxwell's equations in time domain, is the code architecture and design to efficiently implement such equations. Furthermore, to be able to solve these equations in arbitrary geometries and materials, new algorithms need to be developed in order to fill the material regions in the simulation domain.
