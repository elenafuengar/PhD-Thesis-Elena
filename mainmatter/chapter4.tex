This numerical method is the one chosen by the standard and commercial Wakefield solvers used over the last 30 for calculation of beam coupling impedance in arbitrary 3D accelerator structures. Together with the fundamental numerical method schemes described to be able to solve Maxwell's equations in time domain, is the code architecture and design to efficiently implement such equations. Furthermore, to be able to solve these equations in arbitrary geometries and materials, new algorithms need to be developed in order to fill the material regions in the simulation domain. Due to the high computational cost of this simulations, computational optimization such as memory management, domain splitting for multi processing, and GPU compatibility were also explored and implemented during this thesis.
